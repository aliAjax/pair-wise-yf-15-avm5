# hxyfront-62003 法医昆虫学样本记录

法医昆虫学样本登记前端工具：登记采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式与鉴定备注，并把同批补采自动收成「样本链」。

## 样本链规则（规则层 `src/rules/chainRules.ts`，纯函数）

1. **收链**：案件编号、采样地点、采集日（YYYY-MM-DD）三者相同的登记卡归为同一条样本链；链上按采集时间排序，首条即主记录，后续卡为补采。
2. **待复核不覆盖**：主记录已有鉴定结果时，新补采提交的鉴定内容不写入，补采卡只标「待复核」，主记录结论保持不变；主记录事后补录结论时，已有补采同步转「待复核」。
3. **封存退回**：主记录封存后，新的补采申请直接退回并在「案件关联」页留痕，原链卡片与状态不变，鉴定结果只读。
4. **全页面读链**：样本链列表、发育阶段筛选（链上任一卡处于该阶段即命中）、温度记录图（每张卡是一个温度观测点）、样本详情卡全部从同一份链数据派生。

## 分层

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 规则层 | `src/rules/chainRules.ts` | 收链、排序、补采接受/待复核、封存退回、筛选、温度序列、统计指标；不碰存储与 DOM |
| 存储层 | `src/storage/chainStore.ts` | localStorage 读写与版本校验、数据恢复、外部订阅 store；判定全部调用规则层 |
| 页面层 | `src/App.tsx`、`src/components/*` | 登记台、样本链列表、案件关联、温度图（纯 SVG）、详情卡 |

数据只保存在本浏览器 `localStorage`（键 `forensic-sample-chains:v1`），关闭/重开浏览器后自动恢复；无后端、无新增运行时依赖。
